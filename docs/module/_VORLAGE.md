# Funktionssteckbrief – Vorlage

Kopieren in `docs/module/<modul>.md` als neuen Abschnitt. Erst bauen, wenn alle Felder gefüllt sind.

## <KÜRZEL-NN> <Name der Funktion>

| Feld | Inhalt |
| --- | --- |
| Status | entwurf · bereit · in Arbeit · umgesetzt |
| Modul + Stufe | z. B. spools, Stufe 1 |
| Ziel | ein Satz: was der Nutzer danach erreicht hat |
| Ablauf | nummerierte Schritte aus Nutzersicht (max. 3 Tipps nach Scan) |
| Seite | Vorlage (Liste / Detail / Aktions-Sheet / Formular / Scan) + verwendete Bausteine |
| Daten | Bambuddy-Endpunkte lesend / schreibend, Ereignisse |
| Plattform | benötigte Fähigkeiten (`can(…)`), Ersatzweg, wenn eine fehlt |
| Zustände | lädt / leer / Fehler / offline – je ein Satz |
| Rechte | benötigte Bambuddy-Berechtigung |
| Akzeptanz | prüfbare Sätze |
| Offen | Fragen vor dem Bau |
